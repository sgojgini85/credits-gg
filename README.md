# credits.gg

IMDb-style database for video games — who made them, and with what.

- **Live demo (V1):** https://muse.ai/s/credits-gg-2-xhxw63yrxgxdv81
- **`docs/V1-DECISIONS.md`** — frozen record of every product, design, and data
  decision behind the V1 demo.
- **`docs/HOSTING-PLAN.md`** — plan for hosting on a Linux instance
  (static demo first, production app later).
- **`research/`** — franchise research data and notes.
- **`infra/`** — server config and deploy workflows (Phase 1+).
